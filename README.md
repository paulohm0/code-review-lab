# Code Review Lab

Repositório de estudo para praticar leitura de código e code review em Java/Spring Boot.

## Como funciona

- Cada pasta `challenge-NNN-*` é um projeto completo, **gerado por IA (Claude)** com defeitos plantados de propósito e uma task (investigar um problema, refatorar, melhorar ou implementar uma feature).
- Eu trabalho numa branch `solution/NNN-*`, lendo código que não escrevi, encontrando os defeitos e cumprindo a task.
- O trabalho é entregue por **Pull Request**, e a IA faz a **code review** como um tech lead: comenta nas linhas alteradas, faz perguntas sobre minhas decisões e só aprova quando o código estiver bom.
- Não existe gabarito. A avaliação acontece na revisão do PR.

## Aviso

O código dentro das pastas de desafio é **defeituoso de propósito**. Não use como referência de boas práticas.
